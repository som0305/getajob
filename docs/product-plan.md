# getajob 현재 기획

## 방향
모던한 흰색·회색 화면, 큰 캘린더, 파일 서랍. 장식 문구 최소화.

## 공고 입력
검색 및 API 추천에서 **공고 내용 붙여넣기**로 변경했다. API 키 없이 브라우저에서 규칙으로 항목을 추출한다. 실제 AI 분석으로 표시하지 않는다.

회사·직무·서류 마감·전형 일정 후보를 편집 가능한 창에 표시한다. 사용자가 확인·수정 후 저장한다. 회사·직무가 없으면 직접 입력한다. 연도가 없는 날짜·미정·추후 안내는 빈 날짜로 유지한다. 캘린더 추가를 체크한 일정만 등록한다. 공고는 고민중에 보관하며 원문도 저장한다. 같은 원문 중복 저장 방지.

## 지원 관리
고민중 → 서류 지원 → 1차 합격 → 2차 합격 → 최종 합격. 드래그 및 선택 메뉴. 불합격 보관함과 위로 문구, 복원 기능.

## 캘린더
직접 일정 입력. 형광펜을 선택해 드래그. 부분 지우개, 한 획 취소, 월별 지우기. 브라우저 저장.

## 범위
서버 연동·API 인증·공고 검색은 현재 흐름에서 제거. 외부 AI·공고 추천·알림·계정 동기화는 제공하지 않는다. 상세 사용·검증 절차는 README 참고.

## 입력 버튼 보강
정리 결과를 팝업 대신 버튼 아래 인라인 영역에 표시한다. 빈 내용·처리 오류 메시지와 처리 상태를 제공한다. 입력→결과 표시→저장 및 기존 기능 회귀 테스트 통과. 스크립트가 차단된 미리보기는 noscript로 안내한다.

## 확인하고 저장 버튼 수정
저장 버튼을 명시적인 클릭 처리로 변경했다. 회사·직무·날짜 누락과 저장 공간 부족을 화면에 표시한다. HTTPS가 아닌 환경에서 randomUUID가 없어도 공고 ID를 생성한다. HTTP 회귀 테스트, 저장 실패 시 원상 복구·재시도, 새로고침 후 공고·일정 유지를 검증했다.

## 지원 단계 이펙트
최종 합격으로 이동하면 해당 서랍이 열리며 내부에서 색종이 42개와 축하 이모지가 터진다. 불합격 보관함에 이동하면 흔들리는 눈물 이모지와 떨어지는 눈물을 표시한다. 정적 불합격 토스트는 제거했다. 효과는 자동 정리되며 새로고침에는 재생하지 않는다. 드래그와 단계 선택 모두 지원. 움직임 줄이기 설정에서는 짧은 페이드로 대체한다. `node tests/effects.cjs`로 실제 드래그·애니메이션·정리·상태 유지 검증.
